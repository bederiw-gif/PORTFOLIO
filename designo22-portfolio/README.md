# DESIGNO 22 — Portfolio

Portfolio de graphiste designer et UI/UX designer.
Un seul fichier `index.html` (CSS, JavaScript, images et vidéo inclus), sans installation.

## Contenu

- `index.html` : le site complet
- `assets/designo22-cinematic.mp4` : vidéo showreel (aussi intégrée dans le site)
- `assets/designo22-qr.png` et `.svg` : code QR
- `assets/designo22-post-instagram.png` : post Instagram

## Mettre le site en ligne avec GitHub Pages

1. Sur github.com, créez un dépôt public nommé `designo22-portfolio`.
2. Envoyez-y tous les fichiers de ce dossier (bouton « Add file » puis « Upload files »).
3. Allez dans Settings, puis Pages. Dans « Build and deployment », choisissez « Deploy from a branch », la branche `main` et le dossier `/ (root)`, puis Save.
4. Attendez une à deux minutes. Le lien sera :
   `https://VOTRE-NOM-GITHUB.github.io/designo22-portfolio/`

## Avec la ligne de commande

```bash
git init
git add .
git commit -m "Portfolio DESIGNO 22"
git branch -M main
git remote add origin https://github.com/VOTRE-NOM-GITHUB/designo22-portfolio.git
git push -u origin main
```
